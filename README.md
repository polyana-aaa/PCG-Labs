1. Цель работы
Изучить цветовые модели CMYK, RGB и HLS, освоить формулы взаимного перехода между ними, а также разработать интерактивное приложение, которое позволяет задавать цвет и одновременно отображать его представление во всех трёх моделях.

Было создано приложение, которое:

- Позволяет пользователю задавать цвет тремя способами:
  -точным числовым вводом;
  -плавным изменением ползунком;
  -выбором из палитры (системный диалог выбора цвета и готовая палитра).
- Отображает цвет одновременно в трёх моделях: CMYK, RGB, HLS.
- При изменении любой компоненты автоматически пересчитывает значения в остальных двух моделях.
- При выходе значений за допустимые границы показывает предупреждение об обрезке/округлении.

2. Сведения

2.1 Модель RGB
Аддитивная модель, в которой цвет образуется сложением трёх базовых излучений: красного (R), зелёного (G), синего (B). Каждая компонента принимает значения от 0 до 255.

2.2 Модель CMYK
Субтрактивная модель, используемая в полиграфии. Цвет формируется как результат вычитания из белого четырёх красок: голубой (C), пурпурной (M), жёлтой (Y) и чёрной (K). Компоненты задаются в процентах от 0 до 100.

2.3 Модель HLS
Модель, описывающая цвет через три параметра:

H (Hue) — цветовой тон, 0…360°;
L (Lightness) — светлота, 0…100%;
S (Saturation) — насыщенность, 0…100%.

Приложение реализовано в виде одного HTML-файла, содержащего:

HTML-разметку — интерфейс с двумя колонками;
CSS-стили — оформление карточек, полей, палитры, предупреждения;
JavaScript-код — вся логика преобразований и обработки событий.

3. Интерфейс

- Левая колонка:

  квадрат предпросмотра выбранного цвета;
  текстовые значения HEX, RGB, CMYK, HLS;
  кнопки «Случайный цвет», «Чёрный», «Белый»; 
  готовая палитра из 30 цветов.

- Правая колонка:

  блок CMYK — поля и ползунки для C, M, Y, K + выбор цвета;
  блок RGB — поля и ползунки для R, G, B + выбор цвета;
  блок HLS — поля и ползунки для H, L, S + выбор цвета;
  блок предупреждения о выходе за границы.

- Внутреннее представление цвета
  Цвет хранится в переменной currentRgb в виде объекта {r, g, b}. Все изменения любой модели сначала переводятся в RGB, после чего выполняется пересчёт остальных моделей.

4. Возможности пользователя

- Задавать цвет числом в любой модели.
- Плавно менять цвет ползунками.
- Выбирать цвет через системный диалог (три кнопки «Палитра»).
- Выбирать цвет из готовой палитры.
- Использовать кнопки быстрого выбора (случайный, чёрный, белый).
- Наблюдать одновременное представление цвета во всех трёх моделях.
